# 動画クリッピングツール

## 1. プロジェクト概要

### 1.1 目的
複数カメラの映像が1つの画面に統合された動画ファイルから、特定のカメラ映像部分のみを切り出すコマンドラインツールを開発する。

### 1.2 背景
- 複数のカメラ映像が1つのMP4ファイルに統合されている
- 特定のカメラ映像のみを個別に抽出したい
- 同じフォルダ内の複数の動画ファイルに対して一括処理を行いたい

## 2. システム要件

### 2.1 動作環境
- **OS**: macOS
- **プログラミング言語**: Python
- **実行環境**: Python実行環境インストール済み

### 2.2 実行方法
- Pythonスクリプトとして実行
- 実行コマンド例: `python clip_video.py`

### 2.3 依存ライブラリ
- requirements.txtを用意
- pipでインストール可能な形式

## 3. 機能要件

### 3.1 基本機能

#### 3.1.1 フォルダ選択機能
- **入力フォルダ選択**: GUIダイアログで選択
- **出力フォルダ選択**: GUIダイアログで選択

#### 3.1.2 範囲選択機能
- 動画の中間フレームを表示
- 表示サイズ: 元の動画サイズ
- マウスドラッグで矩形範囲を描画
- 選択中は枠線を表示
- **確定**: Enterキー
- **やり直し**: Escキー

#### 3.1.3 一括処理機能
- 入力フォルダ内の全MP4ファイルを対象
- サブフォルダは対象外
- 全ファイルに同じクリッピング範囲を適用
- 無劣化コピー方式(再エンコードなし)
- 音声トラックも含める

### 3.2 実行フロー

```
1. ツール起動
2. GUIで入力フォルダを選択
3. GUIで出力フォルダを選択
4. 入力フォルダ内の最初のMP4ファイルの中間フレームを表示
5. マウスドラッグで範囲選択
6. Enterで確定 / Escでやり直し
7. フォルダ内の全MP4ファイルに対してクリッピング処理を実行
8. 処理完了メッセージを表示
```

### 3.3 進捗表示
- 現在処理中のファイル名を表示
- 進捗バー(処理の進行状況を%)を表示
- 処理完了時はターミナルにメッセージ表示

## 4. 入出力仕様

### 4.1 入力
- **対象ファイル**: .mp4ファイルのみ
- **対象範囲**: 入力フォルダ直下のみ(サブフォルダは除外)
- **ファイル特性**: 数時間の長時間動画、数GB程度

### 4.2 出力
- **出力先**: 指定した出力フォルダ
- **ファイル名**: `{元のファイル名}_clipped.mp4`
- **ファイル形式**: MP4
- **品質**: 無劣化(元の動画と同等)
- **音声**: 元の音声をそのまま含める

### 4.3 クリッピング範囲
- 1つのMP4ファイル内で位置は固定
- MP4ファイルごとに位置・サイズは異なる可能性あり
- 同一フォルダ内の複数ファイルには同じ範囲を適用

## 5. エラー処理

### 5.1 エラーケースと対応

| ケース | 対応 |
|--------|------|
| 動画ファイル以外のファイルが含まれる | スキップして処理続行 |
| 出力フォルダに同名ファイルが存在 | 上書き |
| 処理中にエラー発生 | 処理を停止 |
| エラーが発生したファイル | ファイル名をターミナルに表示 |

## 6. 非機能要件

### 6.1 使用頻度
- 個人使用のみ
- 複数ファイルの一括処理

### 6.2 パフォーマンス
- 大容量ファイル(数GB)の処理に対応
- 無劣化コピー方式により高速処理

### 6.3 ユーザビリティ
- シンプルなコマンドライン実行
- GUIによる直感的なフォルダ選択
- マウス操作による視覚的な範囲選択

## 7. 制約事項

### 7.1 機能的制約
- 1回の実行で1つの範囲のみ選択可能
- 1つの動画から複数の範囲を切り出す機能は不要
- 範囲設定の保存・再利用機能は不要
- ログファイルの出力は不要

### 7.2 技術的制約
- MP4形式のみサポート
- 無劣化コピー方式のため、キーフレーム単位の制限あり(ただし空間的な切り出しには影響なし)

## 8. 想定される使用シナリオ

1. 監視カメラ映像など、複数カメラが1画面に配置された録画ファイル
2. 特定のカメラ映像のみを抽出して保存
3. 同じレイアウトの複数の録画ファイルを一括処理

## 9. 今後の拡張可能性(現時点では不要)

- 複数の範囲を同時選択
- 設定ファイルによる範囲の保存・再利用
- 他の動画形式のサポート
- 音声の有無を選択可能に

## 10. 開発に必要な主要ライブラリ(想定)

- **動画処理**: ffmpeg-python, opencv-python
- **GUI**: tkinter(標準ライブラリ)
- **進捗表示**: tqdm
